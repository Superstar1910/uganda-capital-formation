# Refresh workflow specification
1. Retrieve primary-source releases and preserve unmodified snapshots.
2. Record timestamp, dataset licence, definition, observation period and revision.
3. Validate schema, duplicates, missing observations and stock/flow classifications.
4. Reproduce aggregates and scenario outputs.
5. Compare revisions with previous release; review discrepancies.
6. Submit a reviewable change with evidence; publish only after maintainer approval.
No scheduled data refresh is activated in release 0.1.

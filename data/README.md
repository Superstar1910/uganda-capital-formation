# Data architecture
Separate ledgers: national accounts/real growth; annual investment needs; ultimate capital supply; transaction pipeline; fiscal contingent exposure; operational outcomes. Observation schema: metric, period, calendar/fiscal basis, geography, value/null, currency, unit, price basis, source URL, retrieval timestamp, release version, evidence class, verification status and licence.
Evidence classes: official actual; Oakstone calculation; illustrative assumption; proposed target. A prior paper’s fact label is not independent verification in this release.
Committed, disbursed and new productive uses are separate. Guarantees and intermediaries never become additional funded capital rows. Missing data stay null.
